# Visual, motion and tutorial refinement — in verification

Scope: evolve the verified layout release without changing curriculum, persisted learning definitions, profile schemas, Firebase rules or runtime services.

Implemented: an original SVG book-world welcome illustration; task-specific spacing beneath global navigation; quieter shared surfaces and fewer nested frames; a compact language control with a moving underline; native finite motion for navigation, feedback, selections, placed objects, disclosures and dialogs. Motion never owns the action lock or delays saving. OS reduced motion, explicit reduced motion, Eco and reduced data suppress optional effects. Background redraws resume an in-flight view transition instead of replaying it from zero. New libraries, remote media and runtime AI services: none.

The tutorial audit found a functional state problem: matching always selected the first field, text inputs updated the draft without refreshing guidance, construction hid guidance after selection, and cleanup did not remove the old target marker when the rest of the view stayed mounted. A pure interaction-step resolver now uses response completeness rather than answer correctness. Choice/typing lead to checking; matching advances to the next empty line; writing leads through self-review; submission leads to retry/continue; a toy selection highlights the whole placement scene; a first card flip highlights the remaining board. Successful committed interactions retire guidance. Old receipts remain valid, Help replays the current step, and input updates preserve the editor/caret without rebuilding the form.

Validation now includes real intermediate animation frames, rapid navigation interruption, both language states, reduced motion and Eco, first-view layout, tutorial action-to-action transitions, reload and background redraw. Screenshot generation is not acceptance: inspect candidate images and temporal frames before promoting to main.

Browser references used during implementation: [Web Animations API](https://developer.mozilla.org/en-US/docs/Web/API/Element/animate), [native dialog transitions](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#animating_dialogs), [reduced-motion preference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion). Unsupported animation capabilities degrade to immediate usable state changes. The new SVG is original code-authored artwork following the existing palette and character style.

Verification is pending. Live Google consent, physical mobile devices, screen-reader certification, subjective enjoyment and pedagogical efficacy are not established by automated browser checks. Separate unaccepted curriculum expansion remains outside this release.
