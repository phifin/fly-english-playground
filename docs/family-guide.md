# Playing The Unfolding Atlas

Play at **https://phifin.github.io/fly-english-playground/**.
For a local copy, build with `npm run build` then `npm run preview` (Node 24+),
open `http://127.0.0.1:4173/` and keep that preview process running. Local and
published copies have separate browser storage because their origins differ.

## Your traveler

Create a display name; a nickname is enough. Each traveler has separate answers,
practice recommendations, settings and discoveries. An independent profile can
be chosen as the guardian of dependent profiles. Guardians can open those journals
from Settings. No birthday, microphone recording or contact list is collected.

Local profiles share one browser installation. Anyone controlling that browser
can select them, change settings, read work, or export all its travelers. Use a
trusted device. A dependent link is a family convenience, not a parent PIN or
security restriction. Cloud uses the guardian's approved sign-in for dependents.

Choose a starting band yourself or try the short orientation. Its result suggests
where to practice, with limited confidence; it is not a CEFR certificate. You can
visit every band without completing easier levels first.

## Explore, learn, discover

Each region has four expeditions. Finish an expedition's learning activities to
open the next study mission in that band. Read the English world clue, inspect
the landmarks and help Nim reach the intended place. Water blocks the route;
activate a switch while on or next to it to toggle the bridges.

- **Kids:** meet a clue, try an activity, see the world change, and move Nim with
  direction buttons. The guided trail keeps one moment in view at a time.
- **Balanced:** explore the map, choose activity objectives, queue direction
  commands, then run your route.
- **Serious:** use the direct study queue, review evidence, and enter route
  commands as text when exploring. Commands are N, E, S, W and X (switch).

There is no timer, health loss, streak punishment or purchasable advantage.
Resetting a route preserves discoveries. A world accomplishment needs both
completed learning objectives and a replay-verified destination. It does not
claim English mastery. Use the journal to see those two forms of progress apart.

Choice, constrained word gaps, ordering and matching have bounded answer keys.
Read the task limits before answering; other wording can be natural outside a
restricted exercise. Writing uses a model and self-review checklist, without an
automatic quality score. Feedback explains the objective. You can ask for help;
assisted work is useful practice and is marked separately from fresh recall.

Practice brings back mistakes and scheduled items. An early repeat does not
advance the retention schedule. Seeing an answer prevents same-day retries from
counting as independent retrieval. Retention is an item-level heuristic, not a
validated overall proficiency result. The echo studio offers optional synthesized
listening and spoken retelling without recording or scored speech recognition.

## Change how it feels

Settings keeps experience mode, guidance language, graphical quality and motion
independent. Switching them does not remove progress. Vietnamese assistance helps
with instructions and explanations; assessed passages remain English. Translating
a world clue is an explicit help action. Eco preserves every learning feature;
Auto uses available capability signals and can reduce decoration after slow frames.

Keyboard users can tab through controls. Use arrow keys while focused on the map;
Kids moves directly and other modes add route commands. Every cell has an inspect
button and the landmark legend remains available. Sentence ordering uses buttons,
not mandatory dragging. Turn on reduced motion whenever preferred. Optional
read-aloud depends on the device/browser voice; some voices may use a service.

## Save, back up, recover

Completed responses and executed routes save on this device before success is
shown. Activity drafts save after a short pause and when navigating; watch the
saved/draft status. A browser closed before an outstanding write finishes can lose
the most recent edit. Keep periodic **Settings → Export backup** files somewhere
private. Exports include all local profiles and response text, including writing.

Import validates a backup and merges immutable history by ID; importing twice does
not duplicate attempts. A conflicting event or simultaneous settings revision is
rejected instead of silently overwriting work. Preserve exports from both devices
before resolving a conflict. Clearing site data, switching browser/origin or browser
eviction can remove local profiles; offline cache is not a progress backup.

Built releases install public files for offline use. Wait for Settings to report
that the offline library is ready before depending on a fresh offline reload.
Authentication, synchronization and some synthesized voices still need a network.
An update waits until every atlas tab closes; it does not reload an active lesson.

## Optional family sign-in

The dedicated free cloud service is configured. The owner completes domain and
first-account enrollment in [production status](production-status.md). Sign in
with an approved Google identity, explicitly link a traveler, then synchronize
from Settings. Link
the guardian before dependent profiles. Sync is manual: retry after reconnecting.
Drafts stay device-local; submitted responses, writing and profile metadata sync.

On a new trusted device, sign in and restore your linked profiles. Signing out
does not erase local work. Deleting a remote profile preserves its local copy but
blocks that deleted ID from being uploaded again; export before destructive
actions. Delete dependent cloud copies explicitly before their guardian. Local
and remote deletion are separate controls.
